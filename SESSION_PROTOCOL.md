# SESSION PROTOCOL — Quick Reference

**Print this. Keep it next to you. Follow it every session.**

---

## The 4 Steps

```
START → RESEARCH → WORK → BUT-FOR-REAL → LEARNINGS → END
```

| Step | When | Time | What to Do |
|------|------|------|------------|
| **RESEARCH** | Start of session | 5 min | Read PROJECT_BRIEF.md. Ask "What's #1 priority RIGHT NOW?" |
| **WORK** | Middle of session | Variable | Do the actual task |
| **BUT-FOR-REAL** | After working | 5 min | Ask "What's wrong? What would a farmer hate?" |
| **LEARNINGS** | End of session | 5 min | Update all 3 files with what was learned |

---

## The 3 Files

| File | Purpose | When to Update |
|------|---------|----------------|
| `PROJECT_BRIEF.md` | Living strategy | Start + end of session |
| `SESSION_LOG.md` | Knowledge base | End of session (append) |
| `VALUE_TRACKER.md` | Income tracker | End of session (update numbers) |

---

## Copy-Paste Prompts

### RESEARCH (start of session)
```
I'm working on EthioHerd Connect. Before I start, research:
1. What's the #1 thing I should focus on RIGHT NOW?
2. What would Josh Shpigford say?
3. What's the minimum that ships in 24 hours?
4. What Ethiopian-specific factor am I missing?
```

### BUT-FOR-REAL (after working)
```
I just [what you did]. Be brutally honest:
1. What's wrong with what I did?
2. What would a real Ethiopian farmer say?
3. What would Josh Shpigford say?
4. What's the one thing I should fix before next session?
5. On a scale of 1-10, how much closer am I to 5,000 ETB/month?
```

### LEARNINGS (end of session)
```
Update my project brief based on what we did today:
- What worked: [specific]
- What didn't: [specific]
- Key decision made: [if any]
- ONE thing to remember next session

Update these files:
1. PROJECT_BRIEF.md
2. SESSION_LOG.md
3. VALUE_TRACKER.md
```
